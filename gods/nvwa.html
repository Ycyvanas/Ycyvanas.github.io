女娲 · 炼石造人

AI 前沿 · Agent 工程

创世缘起

往古之时，四极废，九州裂。女娲炼五色石以补苍天，抟黄土以造人。

今之 AI 时代，恰如新一轮创世——大模型如洪荒之力奔涌，Agent 如新生的灵智之体亟待塑造。女娲以此为志：炼石，即探索模型能力边界、打磨工具链；造人，即设计 Agent 架构、赋予智能体自主行动之力。让 AI 不只是对话的玩具，而是能补天地之缺、解人间之难的实在力量。

项目进展

女娲尚在筑基。当前聚焦方向：

  • Agent 框架选型与评估 — LangChain / CrewAI / AutoGen 等框架的实战对比
  • 工具调用与编排 — Function Calling → Tool Use → Multi-Agent 协作链路
  • 大模型应用范式 — RAG / Fine-tuning / Prompt Engineering 最佳实践
  • 端侧推理探索 — 与扶桑协同，将 AI 推理能力下沉到嵌入式设备

发展路线
