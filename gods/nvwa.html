女娲 · 彩石补天

AI 前沿 · Agent 工程

缘起

往古之时，四极废，九州裂，天不兼覆，地不周载。女娲炼五色石以补苍天，断鳌足以立四极。

今日之 AI 世界，态势暗合上古——大模型如洪荒之力奔涌，能力虽强却散落各处，彼此断裂，不成体系。模型与工具之间的裂隙、推理与行动之间的断崖、智能与现实之间的鸿沟，恰如那漏了洞的天穹。

女娲以此为志：炼五色彩石——将各异的大模型、工具链、框架、协议熔于一炉；以石补天——用炼就的能力填补现实世界中未被解决的裂隙。让 Agent 不止于对话，而是能感知、推理、行动、自省的完整智能体。

彩石之炼

每一颗彩石，代表一类 AI 能力。炼石，即是打磨——

🟡 金石 · 大模型 基础模型能力评估与应用范式
🟢 青石 · 工具链 Function Calling · Tool Use · MCP
🔴 赤石 · Agent 框架 LangChain · CrewAI · AutoGen 实战
⚪ 白石 · 知识工程 RAG · 向量检索 · 知识图谱
⚫ 黑石 · 多模态 视觉 · 语音 · 具身智能探索

补天之路

炼石是为了补天。每一块炼就的彩石，都要嵌回现实的裂隙中——

  • 工具调用裂隙 — 让 Agent 真正学会使用工具，打通「想做什么」与「能做什么」之间的断层
  • 协作裂隙 — 多 Agent 协作不再停留在 Demo，而是能稳定运行的生产级编排
  • 记忆裂隙 — Agent 拥有真正的长期记忆，跨会话、跨场景的状态连续性
  • 物联裂隙 — 与扶桑协同，让 Agent 的推理延伸到物理世界，感知并驱动嵌入式设备

发展路线

🟡 炼石期 · 一炼 进行中

  • 大模型 API 调用链路实战（OpenAI / Anthropic / 本地模型）
  • Function Calling 与 Tool Use 工具链对比
  • Agent 框架调研与知识库搭建

⚪ 炼石期 · 二炼 规划中

  • 建设彩石知识库（文档化各方向最佳实践）
  • 实现首个端到端 Agent 原型
  • RAG 知识检索链路实战

⚪ 补天期 规划中

  • Multi-Agent 协作架构落地
  • Agent 记忆与状态管理机制
  • 与扶桑联动：Agent 驱动的物理世界交互
