Agent时代嵌入式开发

在Agent 范式下，嵌入式开发能力体系归纳为五个方面——

  1. 「编译—烧录—监测」闭环 — 从传统工具链扩展为「生成—部署—观测—反馈」动态闭环，让系统状态可被 Agent 解析与诊断。
  2. 资源约束认知 — 理解算力、存储、能耗边界，评估模型部署的工程可行性。
  3. 异构通信协议分层 — 板级外设（I2C/SPI/UART）→ 局域/广域网（Wi-Fi/BLE/MQTT）→ 跨生态互联（Matter），三层贯通。
  4. 感知数据建模 — 传感器物理机理 + 数据预处理（标定/滤波/去噪），实现物理信号到结构化数据的稳定映射。
  5. 设备语义抽象 — 通过物模型/数据点机制，将硬件能力映射为统一接口，为 Agent 提供一致操作空间。

开发板矩阵

从单片机入门到边缘 AI，六阶段学习路线覆盖嵌入式开发全技术栈。

第一阶段 · 嵌入式基础

  • STC89C52RC — 经典 8051 内核，GPIO/中断/定时器/UART，建立底层认知

第二阶段 · 主流 MCU

  • STM32F103 — ARM Cortex-M3，外设驱动/RTOS/工业控制，嵌入式岗位核心技能
  • CH32F103 — 国产 MCU，国产生态入门之选
  • Raspberry Pi Pico (RP2040) — 双核 Cortex-M0+，PIO 自定义协议，创客与快速原型

第三阶段 · AIoT 无线

  • ESP32-S3 — Wi-Fi/BLE 双模，AI 向量指令，连接物理设备与云端智能的关键节点

第四阶段 · 嵌入式 Linux

  • Luckfox Pico — 微型 Linux 开发板，内置 NPU，可运行轻量级 Agent

第五阶段 · FPGA

  • Tang Nano 9K — FPGA 入门首选，Verilog/数字逻辑/HDMI 显示
  • A7-Lite (XC7A35T) — 工业级 FPGA，高速接口/DSP/图像处理

第六阶段 · 边缘 AI

  • Jetson Nano / Orin Nano — GPU 计算，PyTorch/TensorRT/YOLO/大模型推理，构建智能体

🗺️ 推荐学习路线

STC89C52 ──→ STM32 / RP2040 ──→ ESP32-S3 ──→ Luckfox Pico ──→ FPGA ──→ Jetson

接口本质典型应用
GPIO最底层数字开关LED/按键/继电器/中断

JTAG / SWD芯片级控制通道调试/烧录/寄存器访问

📡 板级通信协议

协议特点典型外设

项目进展

📹 ycycam — 智能摄像头系统

基于 ESP32 的端侧摄像头方案，打通了「采集 → 编码 → 推流 → 控制」完整链路。

  • 摄像头驱动 — OV3660，300 万像素，硬件 JPEG 直出
  • 视频推流 — MJPEG over HTTP，多客户端同时观看
  • 远程控制 — 亮度 / 对比度 / 饱和度 / 白平衡等参数 Web 调节
  • 状态面板 — ST7789 240×240 LCD，实时帧率、客户端数、WiFi 信号

📡 ycycam-udp — UDP 智能监测系统

解决 HTTP 推流延迟高、带宽浪费的问题，基于 UDP 自建轻量传输协议。

  • 硬件平台 — ESP32-S3，双核 + PSRAM + 向量指令加速
  • UDP 传输 — 轻量视频流协议，快速传输到服务器端
  • 服务器AI推理 — YOLOv8m 端侧运行，实时检测框叠加视频流
