# 21键红外遥控器（38khz）

| 按键位置 | 按键功能 / 标识 | 键位码（十六进制） |
|---|---|---|
| 第1行第1列 | 🔴 电源 (Power) | 0x45 |
| 第1行第2列 | Mode（模式） | 0x46 |
| 第1行第3列 | 🔇 静音 (Mute) | 0x47 |
| 第2行第1列 | ▶⏸ 播放 / 暂停 | 0x44 |
| 第2行第2列 | ⏮ 上一曲 | 0x40 |
| 第2行第3列 | ⏭ 下一曲 | 0x43 |
| 第3行第1列 | EQ（均衡器） | 0x07 |
| 第3行第2列 | VOL-（音量减） | 0x15 |
| 第3行第3列 | VOL+（音量加） | 0x09 |
| 第4行第1列 | 0 | 0x16 |
| 第4行第2列 | RPT（重复） | 0x19 |
| 第4行第3列 | CLOCK（时钟） | 0x0D |
| 第5行第1列 | 1 | 0x0C |
| 第5行第2列 | 2 | 0x18 |
| 第5行第3列 | 3 | 0x5E |
| 第6行第1列 | 4 | 0x08 |
| 第6行第2列 | 5 | 0x1C |
| 第6行第3列 | 6 | 0x5A |
| 第7行第1列 | 7 | 0x42 |
| 第7行第2列 | 8 | 0x52 |
| 第7行第3列 | 9 | 0x4A |
