# 3. 四个 IO 口总结

| 端口 | 引脚          | 特点                      |
| -- | ----------- | ----------------------- |
| P0 | P0.0 ~ P0.7 | 开漏输出，作为 GPIO 使用时需外接上拉电阻 |
| P1 | P1.0 ~ P1.7 | 标准 GPIO，内部上拉            |
| P2 | P2.0 ~ P2.7 | GPIO，同时可作为高位地址总线        |
| P3 | P3.0 ~ P3.7 | GPIO，同时复用串口、中断、定时器等功能   |

# 6. STC89C52RC 最小系统

```text
             +5V
              │
              │
        ┌─────┴─────┐
        │ STC89C52RC│
        └─────┬─────┘
              │
             GND


      XTAL1 ─┬─ 11.0592MHz
             │
      XTAL2 ─┴─ 晶振


      RST ── 10kΩ ── +5V
        │
       10uF
        │
       GND
```

最小系统至少需要：

* VCC（40脚）接 +5V
* GND（20脚）接地
* XTAL1（19脚）、XTAL2（18脚）接晶振
* RST（9脚）接复位电路
* P3.0（RXD）、P3.1（TXD）连接 USB-TTL 用于下载和串口调试

---

# 7. STC ISP 下载接口

| USB-TTL | STC89C52RC |
| ------- | ---------- |
| TXD     | P3.0（RXD）  |
| RXD     | P3.1（TXD）  |
| GND     | GND        |
| VCC     | 5V         |

注意：

* TX 与 RX 需要交叉连接；
* 下载时通常无需手动按复位键；
* STC-ISP 软件会自动触发下载；
* 推荐使用 CH340、CP2102、FT232 等 USB-TTL 模块。
