# 常见开发板
随着 AI Agent、边缘计算和智能硬件的发展，嵌入式开发板已经从传统单片机扩展到 Linux 开发板、FPGA 开发板以及边缘 AI 开发板。不同类型的开发板对应不同的能力层次，共同构成了现代嵌入式开发技术栈。对于初学者而言，与其从复杂的理论体系入手，不如从开发板出发，逐步建立从硬件控制到智能系统构建的完整认知。
开发板分类概览

| 开发板 | 类型 | 学习重点 |
|--------|------|----------|
| STC89C52RC | 8位单片机开发板 | C语言、GPIO、中断 |
| STM32F103 | MCU开发板 | 外设驱动、RTOS |
| CH32F103 | 国产MCU开发板 | 国产生态、嵌入式开发 |
| Raspberry Pi Pico（RP2040） | MCU开发板 | MicroPython、PIO |
| ESP32-S3 | AIoT开发板 | Wi-Fi、BLE、物联网 |
| Luckfox Pico | Linux开发板 | Linux、边缘AI |
| Tang Nano 9K | FPGA开发板 | Verilog、数字逻辑 |
| A7-Lite（XC7A35T） | FPGA开发板 | FPGA工程设计 |
| Jetson Nano / Orin Nano | AI开发板 | AI推理、机器人 |

---
# 第一阶段：嵌入式基础开发板
这一阶段主要学习单片机的基本工作原理，建立对寄存器、时钟、中断以及外设控制的理解。
STC89C52RC 是经典的 8051 系列开发板，也是许多嵌入式工程师接触的第一块开发板。
其结构简单、资源有限，却能够帮助开发者深入理解单片机的运行机制。
典型学习内容：
- GPIO控制
- LED流水灯
- 按键检测
- 数码管显示
- 定时器
- 外部中断
- UART串口通信
适合建立嵌入式开发的底层认知。

---
# 第二阶段：主流 MCU 开发板
## STM32F103
完成基础学习后，可以进入现代嵌入式开发体系。
STM32F103 是最经典的 ARM MCU 开发板之一，也是嵌入式学习中最重要的平台。同类产品还有CH32F103。
特点：
- 生态成熟
- 资料丰富
- 外设齐全
- 工业应用广泛
重点学习：
- GPIO
- UART
- SPI
- I²C
- ADC
- PWM
- DMA
- FreeRTOS
典型项目：
- 智能小车
- 环境监测
- 数据采集
- 工业控制
很多嵌入式岗位的基础能力要求都围绕 STM32 展开。
## Raspberry Pi Pico（RP2040）
Pico 是树莓派基金会推出的高性价比开发板。
最大特色是 PIO（Programmable I/O）模块，能够自定义硬件通信协议。
适合学习：
- C/C++
- MicroPython
- 自定义通信接口
- 软硬件协同设计
是创客教育和快速原型开发的重要平台。

# 第三阶段：物联网开发板ESP32-S3
AIoT离不开网络连接，因此需要掌握具备无线通信能力的开发板。
ESP32-S3 是目前最流行的物联网开发板之一。
板载：
- Wi-Fi
- Bluetooth LE
- 双核处理器
- AI向量指令
典型项目：
- 智能家居
- 语音助手
- 无线传感器
- 智能机器人
重点学习：
- FreeRTOS
- MQTT
- Wi-Fi通信
- BLE通信
- 云平台接入
对于 Agent 时代而言，ESP32-S3 已经成为连接物理设备与云端智能的重要节点。

---
# 第四阶段：Linux 开发板
当设备开始运行 Linux 时，开发模式将从单片机开发转向完整的软件系统开发。
Luckfox Pico 是近年来非常热门的微型 Linux 开发板。
特点：
- 体积小
- 功耗低
- 支持 Linux
- 内置 NPU
典型应用：
- AI摄像头
- 目标检测
- 智能门禁
- 边缘视觉系统
重点学习：
- Linux系统
- Shell脚本
- SSH远程开发
- Docker
- AI模型部署
对于 Agent 系统开发而言，Luckfox Pico 已经具备运行轻量级 Agent 的能力。

---
# 第五阶段：FPGA 开发板
当 MCU 的实时性和并行处理能力不足时，或当进行加速概念验证时，需要引入 FPGA 技术。
# Tang Nano 9K
Tang Nano 9K 是 FPGA 入门领域最受欢迎的开发板之一。
特点：
- 成本低
- 资源丰富
- 学习门槛较低
适合学习：
- Verilog
- 数字逻辑设计
- 状态机
- VGA显示
- HDMI显示
是 FPGA 入门的首选开发板。

---
# A7-Lite（XC7A35T）
A7-Lite 属于工业级 FPGA 开发板。
相比 Tang Nano：
- 逻辑资源更多
- DSP资源更丰富
- 支持 Vivado 工具链
- 工程应用更广泛
适合学习：
- 高速接口
- DSP设计
- 图像处理
- SoC开发
是从 FPGA 入门走向工程实践的重要阶段。

---
# 第六阶段：边缘 AI 开发板
这是 Agent 系统开发的高级阶段。
Jetson 系列是 NVIDIA 推出的边缘 AI 开发板。
其最大的特点是具备强大的 GPU 计算能力。
典型应用：
- 机器人
- 自动驾驶
- 机器视觉
- 多模态 Agent
可运行：
- PyTorch
- TensorFlow
- YOLO
- TensorRT
- 大模型推理框架
Jetson 系列代表了嵌入式开发从“控制设备”向“构建智能体”的演进方向。

# 推荐学习路线
```text
STC89C52RC（基础硬件控制 / GPIO思维建立）
        ↓
STM32F103 / CH32F103 / RP2040（外设驱动 / 中断 / DMA /FreeRTOS）
        ↓
ESP32-S3（无线通信 / IoT联网 / 云端接入）
        ↓
Luckfox Pico（嵌入式Linux / 驱动与系统 / Docker / 边缘部署）
        ↓
Tang Nano 9K/ A7-Lite （FPGA / 并行计算 / 硬件加速 / 数字系统设计）
        ↓
Jetson Nano / Orin Nano（边缘AI / GPU计算 / 多模态Agent系统）
```
