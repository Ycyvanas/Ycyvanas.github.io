# 通讯接口与协议
在嵌入式系统中，通信能力构成了系统的“神经网络”。从最底层的引脚电平控制，到复杂的网络协议栈与云端通信，整个体系可以抽象为三层结构：
- 物理接口层（Hardware Interface）：定义电气连接与信号形态 。（GPIO / 差分信号）
- 传输协议层（Transport Protocol）：定义数据帧结构与时序规则。（UART / SPI / CAN）
- 应用协议层（Application Protocol）：定义业务语义与交互逻辑 。（MQTT / HTTP / Modbus）
根据是否是接口和协议可分为
## 1. 纯物理接口
仅定义电气行为，不涉及数据协议：
-  GPIO 
-  PWM 
-  ADC / DAC 
-  JTAG / SWD 

---
## 2. 纯通信协议
可运行在多种物理层之上：
-  TCP/IP 
-  MQTT 
-  HTTP 
-  Modbus（应用层） 

---
## 3. 接口 + 协议一体
嵌入式核心通信体系：
-  UART 
-  SPI 
-  I²C 
-  CAN 
-  USB 
-  SDIO 
特点：
 👉 同时定义“线怎么接 + 数据怎么传”

---
# 一、通讯接口（物理层 / 外设层）
通讯接口主要负责电气信号的产生与采集，不直接定义复杂的数据语义。

---
## GPIO（通用输入输出）
最基础的数字控制接口。
核心能力：
-  高/低电平输出 
-  外部电平输入 
-  中断触发 
典型应用：
-  LED控制 
-  按键检测 
-  继电器驱动 
-  软件模拟通信协议（Bit-banging） 
本质：
 👉 最底层“数字开关”

---
## PWM（脉冲宽度调制）
通过占空比表达模拟控制量的数字信号。
应用场景：
-  LED亮度调节 
-  电机调速 
-  舵机控制 
-  蜂鸣器音调生成 
关键参数：
-  频率（Hz） 
-  占空比（%） 
-  分辨率（Timer bits） 

---
## ADC / DAC（模数转换）
模拟世界与数字世界的桥梁。
-  ADC：模拟 → 数字 
-  DAC：数字 → 模拟 
应用：
-  传感器采样（温度/压力/电压） 
-  音频信号处理 
-  电池管理系统 
关键指标：
-  分辨率（12/16/24bit） 
-  采样率 
-  参考电压稳定性 

---
## JTAG / SWD（调试接口）
用于芯片级调试与程序烧录。
JTAG信号：
-  TCK / TMS / TDI / TDO 
SWD信号：
-  SWDIO / SWCLK 
能力：
-  单步调试 
-  Flash烧录 
-  寄存器访问 
👉 属于“芯片级控制通道”

---
## USB物理层（D+ / D-）
高速差分通信接口。
特性：
-  差分信号传输 
-  自动枚举 
-  热插拔支持 
注意点：
-  时钟精度要求高 
-  需匹配终端阻抗 

---
# 二、通信协议（数据规则层）
通信协议定义的是数据如何组织、传输与解析。

---
## UART（异步串口协议）
最基础的串行通信协议。
结构：
 Start + Data + Parity + Stop
特点：
-  无时钟线 
-  异步通信 
-  全双工（TX/RX） 
典型配置：
-  8N1（最常见） 
应用：
-  串口调试 
-  GPS数据 
-  AT指令通信 

---
## SPI（高速同步通信）
高速主从通信协议。
信号：
-  SCLK 
-  MOSI 
-  MISO 
-  CS 
特点：
-  同步时钟 
-  全双工 
-  高速传输（MHz级） 
模式：
-  CPOL / CPHA（4种模式） 
应用：
-  Flash存储 
-  LCD显示屏 
-  高速传感器 

---
## I²C（低速多设备总线）
典型的低速多从机总线。
信号：
-  SDA 
-  SCL 
核心机制：
-  地址寻址 
-  ACK/NACK应答 
-  多主仲裁 
-  时钟拉伸 
特性：
-  需要上拉电阻（4.7kΩ常见） 
-  半双工通信 
应用：
-  IMU传感器 
-  RTC时钟 
-  EEPROM 

---
## CAN（工业级总线协议）
面向高可靠性的分布式通信系统。
特性：
-  差分信号（CAN_H / CAN_L） 
-  抗干扰能力强 
-  多节点广播 
核心机制：
-  CSMA/CR仲裁 
-  优先级决定发送权 
应用：
-  汽车电子 
-  BMS系统 
-  工业控制 

---
## SDIO（存储通信协议）
用于SD卡高速访问。
模式：
-  SPI模式 
-  1-bit / 4-bit SDIO 
特点：
-  命令/响应机制 
-  高带宽存储访问 
应用：
-  TF卡 
-  数据记录 
-  固件存储 

---
## Ethernet（以太网协议栈）
局域网通信标准。
结构：
 MAC + PHY + RJ45
协议栈：
-  TCP 
-  UDP 
-  IP 
-  ARP 
嵌入式实现：
-  LwIP 
-  W5500硬件协议栈 
应用：
-  Web服务 
-  MQTT通信 
-  工业网关 

---
## MQTT（物联网协议）
轻量级发布订阅协议。
模型：
 Publisher → Broker → Subscriber
特点：
-  低带宽 
-  低功耗 
-  弱连接环境友好 
应用：
-  IoT设备 
-  云平台连接 
-  远程控制 

---
## OneWire（单总线协议）
极简通信协议。
特性：
-  单数据线通信 
-  唯一64位ID 
-  可寄生供电 
应用：
-  DS18B20温度传感器 

---
# 三、无线通信协议

---
## Wi-Fi（802.11）
特点：
-  高带宽 
-  中功耗 
-  局域网通信 
典型芯片：
-  ESP32系列 

---
## Bluetooth / BLE
特点：
-  低功耗 
-  手机生态完善 
应用：
-  可穿戴设备 
-  传感器节点 

---
## Zigbee
特点：
-  Mesh网络 
-  超低功耗 
应用：
-  智能家居 

---
## LoRa
特点：
-  超远距离通信 
-  极低功耗 
应用：
-  农业监测 
-  远程传感 

---
## NB-IoT
特点：
-  运营商网络 
-  广覆盖 
-  低功耗 
应用：
-  智能水表 
-  城市物联网
